A small program that writes one short dad joke for make.fun's bounty `u-mfnakmal-dad-joke-showdown-1d2ce3e5`; it prints the character count to stderr and writes the text to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `/output` when that is unset), with no trailing newline.

[![reward](https://make.fun/badge/u-mfnakmal-dad-joke-showdown-1d2ce3e5/AARenor/mf_u_mfnakmal_dad_joke_showdown_1_1_1735/reward.svg)](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5)

```text
My dad sent his steak back twice. When it finally came he clapped for it. The waiter said, 'Sir, that's not how well done works.'
```

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
